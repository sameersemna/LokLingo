## Logging Rules

- Record only changes that alter operational expectations, ownership, thresholds, templates, or review cadence.
- Link affected documents explicitly.
- If a change is reverted, add a new entry instead of editing history.
- Review the latest 90 days of entries during quarterly governance review.
